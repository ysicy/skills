# metadata

- **Название:** api-test-generation
- **Автор:** <ФИО автора>
- **Версия:** 1.0.0
- **Описание:** Harness для генерации API-автотестов на Python (pytest, Allure) по тест-кейсу Jira/Zephyr или спецификации OpenAPI/Swagger: оркестратор ведёт 7 субагентов (анализ контура проекта, требования, сценарии, генерация, ревью, исправление, прогон) с гейтами качества, детерминированные шаги выполняют скрипты
- **Применимость:** Python-проекты с pytest; API-тесты по тест-кейсу с шагами и ожидаемыми результатами либо по OpenAPI-спецификации; нужен доступ к тестовому стенду
- **Использование:** Установить как GigaCode extension командой `gigacode extensions install <путь-к-extension>` и запускать через `/api-test-generation <ссылка на кейс или спецификацию>`
- **Эксперимент:** Проверено на реальных тест-кейсах и публичном API: тест повторяет шаги и ожидаемые результаты кейса без добавленных проверок, недостающие данные запрашиваются у пользователя, по итогам прогона собирается накопительный дашборд
